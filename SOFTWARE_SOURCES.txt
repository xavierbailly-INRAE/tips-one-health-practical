SOFTWARE AND SCIENTIFIC SOURCES

TiPS 1.3.0 - Trajectories and Phylogenies Simulator
Authors: Gonche Danesh, Emma Saulnier, Olivier Gascuel, Marc Choisy,
Samuel Alizon. Package license: GPL (>= 2), as recorded in its DESCRIPTION.
Project: https://gitlab.in2p3.fr/ete/tips/
Methods: Danesh et al. (2022), https://doi.org/10.1111/2041-210X.14038
The installed TiPS package is not redistributed in this student folder.
The teaching wrapper calls its native simulator builder and locally modifies
one generated file-deletion statement to retain early-extinction traces.
It does not change biological propensities or random-number draws.

ape is used for phylogenetic tree handling and parsimony calculations.
Package information and citations: run citation("ape") in R.
TiPS citation information: run citation("TiPS") in R.

This notice identifies upstream software; it does not assign a new license
to the teaching documents or original teaching code.
